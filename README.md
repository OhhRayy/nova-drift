NOVA DRIFT is a neon arena survival shooter that runs entirely offline in a desktop browser. Pilot the light-ship Kestrel through the Ember Reef: harvest star-embers to raise your combo multiplier, blast void shards into sparks, and survive waves that grow faster, denser, and stranger — drifters, spinners, and sine-weaving wraiths, with a storm surge every fifth wave. Grab power-ups (Triple Shot, Aegis Shield, Ember Magnet, Overdrive), chain pickups without taking a hit, and chase the best score. Three hulls. No second chances.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests: the game is static files under `game/`, all art drawn in code and all sound synthesised with WebAudio.

## Controls

- WASD or arrow keys — steer
- Mouse — aim, hold click or Space — fire
- P or Esc — pause · M — mute · R — restart
